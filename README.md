# Littlelemon — Restaurant Website

A responsive, single-page restaurant showcase for Littlelemon, featuring an ocean-blue glass UI, tactile analog-inspired buttons, menu highlights, a journal/blog section, and a contact form.

## Run locally

No build step or dependencies required. Open `index.html` in a browser, or serve the folder with any static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## What's included

- Responsive navigation with mobile menu
- Hero, restaurant story, menu showcase, journal/blog cards, and contact section
- Glassmorphism surfaces and ocean-blue / lemon colour palette
- Raised, beveled buttons with hover and pressed states
- Accessible labels, keyboard-friendly controls, and reduced-motion support
- Contact form validation with a `mailto:` handoff

## Before launch

Replace the sample menu items/prices, location, opening hours, email address, social links, and sample journal copy with approved business information. The contact form currently opens the visitor's email application; connect a form backend (for example Formspree, Netlify Forms, or your own API) to receive submissions without relying on the visitor's mail client. Replace the `.example` email address before publishing.

Food photography is loaded from Unsplash URLs and requires an internet connection.
